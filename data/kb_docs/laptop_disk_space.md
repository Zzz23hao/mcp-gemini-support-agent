# Laptop Disk Space

## Background
Low disk space can prevent updates, builds, and security tools from running correctly.

## Symptoms
- The laptop shows a low storage warning.
- Build tools fail to write files.
- System updates cannot be installed.

## Troubleshooting Steps
1. Ask the user to check available disk space.
2. Remove old downloads, logs, and temporary files.
3. Clear package manager caches.
4. Move large personal files to approved storage.
5. Reboot and retry the failed operation.

## Common Errors
- No space left on device
- Update failed due to insufficient storage
- Build cache write failed

## Escalation
Escalate to endpoint support if disk cleanup does not restore enough free space.
