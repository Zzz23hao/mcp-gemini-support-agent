# Account Lockout

## Background
Users may be locked out after repeated failed sign-in attempts or suspicious authentication activity.

## Symptoms
- The user sees an account locked message.
- Password reset does not immediately restore access.
- Sign-in attempts fail across multiple applications.

## Troubleshooting Steps
1. Confirm the user's corporate email address.
2. Check the identity console for lockout status.
3. Verify whether the lockout was caused by failed password attempts or security policy.
4. Ask the user to reset the password if required.
5. Unlock the account after confirming the user's identity.

## Common Errors
- Account temporarily locked
- Too many failed attempts
- Risk-based sign-in blocked

## Escalation
Escalate to identity security if the lockout was triggered by suspicious activity or impossible travel.
