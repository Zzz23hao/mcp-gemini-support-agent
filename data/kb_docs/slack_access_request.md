# Slack Access Request

## Background
Slack workspace and channel access should be granted based on business need and approval.

## Symptoms
- The user cannot join the workspace.
- A private channel is not visible.
- Slack SSO login fails.

## Troubleshooting Steps
1. Confirm the workspace and channel name.
2. Verify the user's employment status and identity group.
3. Check whether the channel is private or restricted.
4. Ask the channel owner to approve access if needed.
5. Reinvite the user or refresh SSO assignment.

## Common Errors
- User not invited
- Channel not found
- SSO assignment missing

## Escalation
Escalate to collaboration tools admin if workspace invitation or SSO assignment fails.
