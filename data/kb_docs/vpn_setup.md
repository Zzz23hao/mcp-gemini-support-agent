# VPN Setup

## Background
Users need the approved VPN client and profile to access internal resources from outside the corporate network.

## Symptoms
- The user cannot access internal sites from home.
- The VPN client is missing.
- The VPN profile has not been installed.

## Troubleshooting Steps
1. Confirm the user's device is enrolled and compliant.
2. Install the approved VPN client from the device management portal.
3. Download the corporate VPN profile.
4. Sign in with SSO and complete MFA.
5. Test access to an internal status page.

## Common Errors
- VPN profile missing
- Device not compliant
- MFA challenge failed

## Escalation
Escalate to network engineering if the approved profile installs but cannot connect.
