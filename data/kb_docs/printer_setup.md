# Printer Setup

## Background
Users may need help connecting to approved office printers from managed devices.

## Symptoms
- The printer does not appear in the device list.
- Print jobs remain queued.
- The user cannot install the printer driver.

## Troubleshooting Steps
1. Confirm the office location and printer name.
2. Verify the user is connected to the corporate network or VPN.
3. Install the approved printer profile.
4. Clear stuck print jobs.
5. Print a test page.

## Common Errors
- Printer offline
- Driver unavailable
- Access denied to print queue

## Escalation
Escalate to workplace IT if the printer is offline for multiple users.
