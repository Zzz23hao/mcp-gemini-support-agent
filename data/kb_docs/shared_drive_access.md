# Shared Drive Access

## Background
Shared drive access controls team documents, project files, and restricted business records.

## Symptoms
- The user cannot open a shared folder.
- A file link returns access denied.
- The user can view but not edit a document.

## Troubleshooting Steps
1. Confirm the shared drive or folder URL.
2. Verify the user's business need and approval.
3. Check current group or direct permissions.
4. Grant the minimum required role.
5. Ask the user to refresh the page and retry access.

## Common Errors
- Access denied
- File not found
- Edit permission required

## Escalation
Escalate to collaboration tools admin if ownership is unclear or restricted data is involved.
