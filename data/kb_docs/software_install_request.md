# Software Install Request

## Background
Software installation requests must be checked for approval, licensing, security review, and device compatibility.

## Symptoms
- The user cannot install an application.
- The software is blocked by endpoint policy.
- A license prompt appears after installation.

## Troubleshooting Steps
1. Confirm the software name, version, and business justification.
2. Check whether the software is in the approved catalog.
3. Verify license availability.
4. Install through the approved device management portal.
5. Ask the user to restart the application after installation.

## Common Errors
- Installer blocked
- License not available
- Application not approved

## Escalation
Escalate to software asset management if the software needs purchase or security approval.
