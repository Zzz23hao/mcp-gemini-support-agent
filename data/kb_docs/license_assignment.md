# License Assignment

## Background
Users need the correct product license before they can access licensed applications and premium features.

## Symptoms
- The application says the user does not have a license.
- Premium features are hidden.
- Access works for teammates but not for the user.

## Troubleshooting Steps
1. Confirm the user's corporate email address.
2. Check the admin console for assigned licenses.
3. Verify the user is in the correct license group.
4. Ask the user to sign out and sign in again.
5. Wait for license propagation and retest access.

## Common Errors
- License required
- Feature not included in plan
- User not assigned to product

## Escalation
Escalate to software asset management if the team has no available licenses.
