# Security Incident Report

## Background
Potential security incidents must be documented quickly and routed to the security operations team.

## Symptoms
- The user reports suspicious login activity.
- A secret or token may have been exposed.
- Malware or phishing is suspected.

## Troubleshooting Steps
1. Collect the reporter, affected account, timestamp, and evidence.
2. Do not delete suspicious messages or logs.
3. Disable exposed credentials if approved by policy.
4. Create a security incident ticket with high priority.
5. Notify the security operations channel.

## Common Errors
- Missing evidence
- Incorrect severity
- Exposed credential not revoked

## Escalation
Escalate immediately to security operations for credential exposure, malware, or account compromise.
